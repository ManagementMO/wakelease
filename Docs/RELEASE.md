# Release checklist and procedure

The maintained release procedure is [RELEASING.md](RELEASING.md). It covers source builds, architecture inspection, hardened-runtime signing, notarization, final checksums, publication, Homebrew preparation and rollback.

Use [TESTING.md](TESTING.md) for the evidence required before a supported release. Source publication or an ad-hoc signature does not satisfy signed-peer or physical-sleep verification. Private vulnerability reports belong in the repository's GitHub Security Advisories channel, not public issues.

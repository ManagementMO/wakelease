# Release checklist and procedure

The maintained release procedure is [RELEASING.md](RELEASING.md). It covers the no-membership community DMG/pkg path, architecture inspection, protected component pins, repair/removal, optional Developer ID notarization, final checksums, publication, Homebrew limitations and rollback.

Use [TESTING.md](TESTING.md) for the evidence required before a supported release. Source publication, an ad-hoc signature, or a dummy-package result does not satisfy full installed-product or physical-sleep verification. Private vulnerability reports belong in the repository's GitHub Security Advisories channel, not public issues.
